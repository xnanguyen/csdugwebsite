## Prompt

Create a transparent PNG pixel-art scenery asset of stationary night cloud banks, using attached image ONLY as a cloud-shape/style reference. Widescreen 1536x1024, genuine transparent background. Only clouds, absolutely no sky fill, stars, moon, trees, buildings, ground or text. Large irregular sweeping banks coming inward from left edge lower half and right edge upper half, generous completely transparent middle. Clouds have broad stepped pixel silhouettes and a few nested shadow planes, wispy broken tapering ends, consistent crisp coarse pixels like 1990s adventure-game background art. Muted twilight palette: blue-lavender shadows #454c76 and #596087, dusty muted lilac midtone #77718f, very restrained mauve highlights #a28b9e. No white or bright pink, no gradients, blur, glow or halos. Clouds should be quiet and atmospheric, not standalone cartoon cloud icons. Clouds taper out at top and bottom so they layer naturally into a blue night sky. Flat color blocks, not textured painted or photoreal.
